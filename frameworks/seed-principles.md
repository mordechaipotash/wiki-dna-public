# SEED Principles

**Seeds, Ecosystem, Evolution, DNA** -- but also: Bottleneck, Compression, Agency, Seeds.

## Definition

> "Seeds don't describe thinking. They transfer it."

Not documentation. Transmission. The difference between reading about someone's idea and EXPERIENCING it.

> "Seeds are JSON files that activate in any AI. No install. No app. No platform. Just paste, type 'unpack', and journey."

> "A seed is a JSON file that runs inside any LLM. You don't read it. You journey through it. Your choices shape the path."

The 4 SEED principles as cognitive operating system:

1. **BOTTLENECK** -- My monotropic focus is my superpower. Amplify depth, not breadth.
2. **COMPRESSION** -- Say more with less. No verbose explanations.
3. **AGENCY** -- I control direction. You provide execution reach.
4. **SEEDS** -- Small prompts produce large outputs. Trust the depth.
