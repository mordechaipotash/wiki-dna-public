# Monotropism Stack

Monotropism as operating system, not deficit.

## Definition

> "I am almost always hyper focused and find it very hard to switch focus."

> "build monotropism"

Monotropism (Murray, Lesser, Lawson 2005) describes an attention style where cognitive resources flow intensely toward a single focus rather than distributing broadly. The Monotropism Stack is the author's reframe: monotropism isn't a symptom or deficit to be managed -- it's a cognitive operating system with specific capabilities and constraints.

## Genesis

### The Academic Foundation

Monotropism was introduced by Dinah Murray, Wen Lawson, and Mike Lesser (2005) in "Attention, monotropism and the diagnostic criteria for autism." It proposes that autistic cognition is characterized by intense focus on few interests rather than broad attention distribution.

## Evolution

### As Operating System

| Feature | Monotropic OS | Neurotypical OS |
|---------|--------------|-----------------|
| Attention | Deep, single-thread | Broad, multi-thread |
| Switching cost | 30-60 min per major switch | Minutes |
| Interest drive | ICNU (Interest, Challenge, Novelty, Urgency) | Schedule/demand-driven |
| Depth capacity | Extreme (100+ hr hyperfocus bursts) | Moderate |
| Breadth capacity | Sequential only | Parallel |
| Recovery | Requires downtime after bursts | Gradual |

### The Tunnel Metaphor

The monotropic state is a tunnel: deep, focused, productive, but isolated from external context. The tunnel creates the conditions for:
- Hyperfocus bursts (the superpower)
- Context loss on switching (the cost)
- Social blindness during focus (the trade-off)
- Extraordinary depth (the output)

### Implications for Tool Design

If monotropism is a valid construct, tools should:
1. Minimize interruptions
2. Preserve context (save state so switching cost is reduced)
3. Support depth (long sessions, not quick interactions)
4. Follow interest (adapt to user focus, don't force sequences)

Brain MCP does all four. It's a monotropic prosthetic: preserves tunnel state, reduces switching cost, supports depth-first sessions.
