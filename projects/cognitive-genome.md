## What It Is

"Cognitive genome sequencing" -- 12 mining agents that extract patterns, principles, and intellectual DNA from 450+ resources (conversations, documents, repos, transcripts). The systematic harvesting of the author's thinking into structured, searchable, citable form.

## Why It Exists

339K+ messages contain genuine intellectual capital, but it's buried in conversational noise. Cognitive Genome runs automated mining agents that extract: signature phrases, thinking trajectories, decision patterns, SEED alignments, domain expertise markers, and cognitive patterns. The output feeds [[brain-mcp]], [[poly-wiki]], and the broader [[cognitive-genome]] project.

## Technical Stack

- **Agents:** 12 specialized mining agents (Python)
- **AI:** Claude API for extraction and synthesis
- **Data source:** [[brain-mcp]] embeddings and conversations
- **Output:** Structured JSONL, markdown summaries
- **Tools:** Brain MCP tools (cognitive_patterns, thinking_trajectory, what_do_i_think)
